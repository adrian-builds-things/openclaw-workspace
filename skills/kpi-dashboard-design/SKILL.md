# kpi-dashboard-design

Source: https://skills.sh/wshobson/agents/kpi-dashboard-design

## Use
Use this skill when building or refactoring KPI/revenue/operations dashboards and metric views.

## Standard
- Prioritize decision metrics over vanity metrics.
- Group KPIs by decision horizon (today/week/month).
- Keep one-screen scannability and explicit drill-down paths.
- Include definitions and data freshness cues.
