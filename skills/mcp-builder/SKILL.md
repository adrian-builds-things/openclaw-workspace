# MCP Builder

Source: https://skills.sh/anthropics/skills/mcp-builder

## Implementation phases
1. Research MCP protocol + target API/service.
2. Plan tool coverage (prefer broad API coverage; add workflow tools where useful).
3. Implement server core (auth, errors, pagination, response formatting).
4. Implement tools with robust input/output schemas and actionable errors.
5. Test with build + inspector and quality checklist.
6. Create realistic evaluations for multi-step tool usage.

## Quality bar
- Clear tool names and discoverability.
- Strong schema validation and structured outputs.
- Actionable, fix-oriented error messages.
- Read-only/destructive hints set correctly.
