# focus-timeboxing-8020

Source: https://skills.sh/lyndonkl/claude/focus-timeboxing-8020

## Use
Use this skill when planning execution, deciding priorities, and structuring focused work blocks.

## Standard
- Identify high-impact 20% tasks first.
- Timebox execution into clear focus blocks.
- Define explicit outputs per block.
- Review and adjust based on outcomes, not activity.
