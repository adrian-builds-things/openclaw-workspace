# Skill Creator (external pack)

Source: https://skills.sh/anthropics/skills/skill-creator

## Workflow
1. Clarify concrete use-cases and trigger examples.
2. Plan reusable assets (scripts/references/assets).
3. Create/modify `SKILL.md` with precise `name` + `description`.
4. Keep body concise and procedural; move long details to references.
5. Validate structure and iterate after real usage feedback.

## Rules
- Prefer concise, high-signal guidance.
- Description must include "when to use" and examples.
- Avoid extra docs clutter; keep skill folders minimal.
- Use progressive disclosure to reduce context bloat.
