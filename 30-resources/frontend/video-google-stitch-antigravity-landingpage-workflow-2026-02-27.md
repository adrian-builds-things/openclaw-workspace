# Video-Auswertung: Google Stitch + Antigravity für Landingpages

Erfasst am: 2026-02-27  
Video: https://youtu.be/SK_sSNyJ758?si=Mae6gs3C5w-cGu04

## Kurzfazit
Sehr guter Workflow für „Design-first“ Landingpage-Bau: erst UI sauber evaluieren, dann in Stitch Abschnitt für Abschnitt designen, anschließend über MCP in React umsetzen.

## Kern-Workflow aus dem Video (komprimiert)
1. **Aktuelle Landingpage evaluieren** (Conversion-Lücken identifizieren: Hero, CTA, Trust, Social Proof, Value etc.).
2. **Stitch per MCP mit Coding-Agent verbinden** (Antigravity/ähnlich).
3. **Prompt-Qualität verbessern** (enhanced prompts), dann **Section-by-Section** designen statt alles auf einmal.
4. **Design reviewen/freigeben** in Stitch.
5. **Design in React-Komponenten übersetzen** (mit Fokus auf Design-Tokens, Konsistenz, UI-Genauigkeit).
6. Iterativ auf nächste Sektionen gehen, bis komplette Landingpage steht.

## Wichtigste Learnings für Adrian
- **Nicht full redesign in einem Shot.** Höhere Qualität entsteht sectionweise.
- **Erst Diagnose, dann Design.** Ohne Gap-Analyse wird’s nur „hübsch“, aber nicht besser konvertierend.
- **MCP-Bridge spart massiv Zeit.** Kontext + Assets + Design fließen besser in die Implementierung.
- **Design-System-Disziplin ist Pflicht.** Nur so bleibt das Ergebnis nicht „AI-bunt“, sondern produktionsreif.
- **Conversion-Elemente priorisieren:** Hero-Message, CTA-Klarheit, Trust Bar, Vergleich/Proof, Pricing.

## Anwendung auf deine Landingpages (MindTrajour/Bite Club)
- Sprint 1: Hero + CTA + Trust-Block redesignen.
- Sprint 2: Problem/Agitation + Value + Comparison-Section.
- Sprint 3: Testimonials + Pricing + FAQ/Objection Handling.
- Nach jedem Sprint mini QA: Lesbarkeit, mobile Layout, CTA-Visibility, Konsistenz der Komponenten.

## 30-Minuten-Startplan (morgen)
1. Zielseite wählen (z. B. MindTrajour Landing).
2. 5 größte Conversion-Gaps notieren.
3. Nur **eine** Section in Stitch neu designen.
4. In React umsetzen lassen.
5. Vorher/Nachher Screenshot + kurze Bewertung dokumentieren.
