# Obsidian Task System (empfohlen)

## Kurzantwort
CardBoard ist okay als Visual-Layer, aber **nicht** als alleinige Basis.

Stabiler Stack für dich:
1. **Tasks** (Pflicht)
2. **Dataview** (Pflicht)
3. **Kanban** (optional, für Board-Ansicht)

---

## Was du installieren musst

### Pflicht
- **Tasks** (Community Plugin)
- **Dataview** (Community Plugin)

### Optional (Board-Ansicht)
- **Kanban** *(empfohlen, sehr stabil)*

### So installierst du in Obsidian
1. `Settings → Community plugins`
2. `Safe mode` deaktivieren
3. `Browse` öffnen
4. Nacheinander installieren + aktivieren:
   - `Tasks`
   - `Dataview`
   - optional `Kanban` oder `CardBoard`

## Kanban richtig nutzen
Die Datei [[00-cockpit/tasks-board|Tasks Board]] ist im Kanban-Format angelegt.
Wenn das Kanban-Plugin aktiv ist, siehst du direkt die Board-Ansicht statt einer reinen Liste.

## 5-Minuten-Regel (Daily)
1. Neues landet immer in [[00-cockpit/tasks-inbox|Tasks Inbox]]
2. 1× täglich Inbox leeren → nach [[00-cockpit/tasks-master|Tasks Master]]
3. Max. 3 aktive `Doing`-Tasks gleichzeitig
