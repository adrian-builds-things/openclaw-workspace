# Bot Souls (Brain/Muscle Setup)

Diese Souls sind für einen kosteneffizienten Multi-Bot-Stack ausgelegt.

## Empfohlene Bot-Struktur (7 Rollen, schlank geschnitten)

1. `01_orchestrator_po.md` → PO + Priorisierung + Kanban-Steuerung
2. `02_engineering_architect.md` → Dev + SW-Architektur + Delivery
3. `03_growth_copy_seo.md` → Landingpages + Copy + SEO + Marketing-Messaging
4. `04_analytics_experimentation.md` → Tracking + Dashboards + A/B-Test-Auswertung
5. `05_content_studio.md` → Content-Ideen + Erstellung + Repurposing
6. `06_outbound_prospecting.md` → Lead-Suche, Enrichment, personalisierte Email/LinkedIn-Preps (BC/MTJ)
7. `07_executive_productivity.md` → Ideen/Infos/Termine, Priorisierung, Timeboxing, Tagessteuerung

## Warum diese Zusammenfassung?

- Weniger Kontextverlust zwischen zu vielen Mikro-Bots
- Klarere Verantwortlichkeiten
- Bessere Kostenkontrolle durch Modell-Routing pro Bot
- Einfachere Kanban-Zuordnung (pro Ticket ein Lead-Bot)
