# Manne Share Vault

Dieser Vault ist die gemeinsame Arbeitsfläche zwischen Adrian (Obsidian auf Mac) und Manne (VPS).

## Prinzip
- Du wirfst alles schnell in `00-inbox/`.
- Manne sortiert in die passenden Bereiche.
- Manne arbeitet danach direkt in dieser Struktur weiter.

## Struktur
- `00-inbox/` → Eingang (unsortiert)
- `10-domains/` → operative Domänen
  - `biteclub/`
  - `mindtrajour/`
  - `sales/`
  - `ops/`
- `20-playbooks/` → SOPs, Checklisten, Prozesse
- `30-decisions/` → Entscheidungen inkl. Kontext
- `40-content/` → Content-Assets
  - `linkedin/`
  - `blog/`
  - `landing-pages/`
- `50-resources/` → Quellen, Research, Referenzen
- `90-archive/` → erledigt/alt
- `99-system/` → Regeln, Templates, Workflow-Dateien

## Regel
Wenn unklar: erst in `00-inbox/`, dann sortieren.
