# from-mac Inbox

Dropzone für Mac -> Server via Syncthing.

Regel:
- Neue Dateien hier ablegen.
- Manne sortiert sie nach `[[OBSIDIAN_ROUTING]]` in die Zielordner ein.
- Verarbeitete Dateien wandern nach `00-inbox/processed/` oder werden im Zielordner abgelegt.
