# Agent Usage

## Verfügbare Spezial-Agenten
1. `trading-analyst` (MindTrajour)
2. `facility-ops-analyst` (Bite Club)

## Wie du sie ansprichst (einfach im Chat)
Schreibe einfach:
- `@trading-analyst ...`
- `@facility-ops-analyst ...`

Oder in natürlicher Sprache:
- "Frag den Trading Agent: ..."
- "Lass den Facility Ops Agent analysieren: ..."

Der Main-Agent routed dann an den passenden Spezial-Agenten.

## Gute Prompt-Patterns
- Ziel + Kontext + gewünschtes Outputformat
- Beispiel: "@trading-analyst Priorisiere die nächsten 3 Features für Anfänger-Trader. Output: Insight/Evidence/Impact/Next Action + KPI."
- Beispiel: "@facility-ops-analyst Welche 3 Ops-Risiken blockieren Rollout in neuem Standort?"
