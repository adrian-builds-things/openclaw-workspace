## Sales Frameworks

### Discovery Framework (SPIN)
- **Situation:** Was nutzen sie aktuell?
- **Problem:** Welche Probleme entstehen dadurch?
- **Implication:** Was kostet das Problem?
- **Need-Payoff:** Was wäre anders wenn das gelöst ist?

### Einwand-Handling
| Einwand | Antwort |
|---------|---------|
| "Zu teuer" | ROI-Rechnung (Waste-Kosten vs. Investition) |
| "Kein Budget" | "Wann wäre ein Budget da? / Pilot-Option" |
| "Kein Bedarf" | "Sind Sie von der EU Directive ausgenommen?" |
| "Keine Zeit" | "Das Setup dauert 2 Stunden. Wir machen alles." |
| "Schon Lösung" | "Was fehlt euch dabei noch?" |
