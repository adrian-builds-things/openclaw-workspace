# Revenue Scoreboard Workflow (Simple, 15 min/day)

_Last updated: 2026-02-16_

## Goal
Create daily visibility into whether outreach is converting into revenue.

## Tooling (minimal)
- One Google Sheet or Notion table using `daily-revenue-scoreboard-template.md`
- One daily check-in slot (EOD, 10–15 min)

## Daily Routine
1. **Collect raw numbers** from LinkedIn/email/calendar/CRM notes.
2. **Fill one row** in scoreboard table.
3. **Write 5-line summary** (wins, blocker, next move).
4. **Decide one lever for tomorrow**:
   - lead volume,
   - message quality,
   - follow-up speed,
   - call-to-proposal conversion.

## Weekly Review (30–45 min, Friday)
- Compute conversion steps:
  - Outreach -> Reply
  - Reply -> Call booked
  - Call held -> Proposal
  - Proposal -> Win
- Identify weakest step.
- Commit one experiment for next week (single variable only).

## Data hygiene rules
- No empty definitions (use same metric definitions each day).
- No vanity metrics only — always tie to calls, proposals, wins.
- Keep notes short and decision-focused.

## Escalation rule
If **5 business days with 0 calls booked** OR **10 business days with 0 proposals**, trigger a GTM reset:
- Re-check ICP targeting,
- Re-write opener/call-to-action,
- Increase follow-up cadence.

## Review shortcut for Adrian
- Open latest 7 rows.
- Check trend in: positive replies, calls booked, proposals sent, revenue closed.
- Read notes column for blockers requiring decision.
